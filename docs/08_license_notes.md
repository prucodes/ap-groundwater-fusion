## Official APWRIMS/APSAC/RTGS Boundaries

Official APWRIMS/APSAC/RTGS boundaries are required for official mandal-level outputs. Public prototype boundaries must not be used to claim official APWRIMS/AWARE results.

Official flags may be set only after official AP government/APWRIMS data is actually supplied and verified.
