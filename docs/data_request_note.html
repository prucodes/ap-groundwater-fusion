Andhra Pradesh · Groundwater Intelligence Layer

APWRIMS Data Request — 3–5 District Proof-of-Concept

A non-official, decision-support prototype that fuses APWRIMS ground readings with open NASA / satellite signals (GRACE-FO, CHIRPS, TerraClimate). This note specifies a one-time sample export to validate the system on real data.

Purpose & assurance. Outputs will be clearly labelled prototype / not official and will not be presented as official groundwater results. Satellite values are percentiles / millimetres — never groundwater depth. We request a one-time sample now; a live feed/API is a later production step.
