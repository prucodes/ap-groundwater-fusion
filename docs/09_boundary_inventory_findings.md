## Mandal/Subdistrict Availability

Plausible AP mandal/subdistrict polygons exist in the fetched public prototype sources. The standardized V0 layer uses the datta07 AP subdistrict polygons.

This does not mean the layer is official or current. It is only a prototype spatial join layer until official APWRIMS/APSAC/RTGS mandal boundaries are supplied.

## Limitations

- datta07 AP district/subdistrict files appear aligned to older 13-district structures in some files, while separate new-district files contain 26 districts.
- satishvmadala has a `TODO-GeoJSONS/MANDAL.geojson` candidate with 696 features, but its folder name and missing CRS require additional review before use.
- Name spellings can differ from APWRIMS/AWARE expectations. The mock station join already surfaced a prototype spelling mismatch: `Tadipatri` vs `TADPATRI`.
- CRS is unknown for several AP files, including the satishvmadala district and mandal candidates and the datta07 AP village/new-district files.
- Public GitHub datasets may be stale, incomplete, or inconsistent with current official AP administration.

## Official Requirement

Official APWRIMS/APSAC/RTGS mandal boundaries are still required before official mandal-level outputs can be claimed.
